# Data Driven Modeling and Simulation
Repo for the Homeworks of Data Driven Modelling 

## Folder Structure
A folder for each milestone is created.
For example: M2 folder is for the second milestone 'What if Scenarios'.

## How to Run
create a virtual environment, install dependencies.

- For M2: run the `whatif.py` file. all scenarios can be found in `scenarios.py`
